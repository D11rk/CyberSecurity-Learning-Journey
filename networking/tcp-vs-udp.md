# TCP vs UDP

## What I learned today
- TCP and UDP are two major transport layer protocols used for communication.
- TCP is reliable, connection‑oriented, and ensures data arrives correctly.
- UDP is fast, connectionless, and does not guarantee delivery.
- Ports help identify which service or application should receive the data.

## TCP is Used for:
- HTTP/HTTPS
- SSH
- Email
- File transfers

## UDP Used for:
- Gaming
- Video streaming
- Voice calls
- DNS

## Common ports:
- 80 → HTTP
- 443 → HTTPS
- 22 → SSH
- 53 → DNS
- 25 → SMTP
- 21 → FTP

## Notes
- TCP is used when accuracy matters.
- UDP is used when speed matters.
- Ports + IP address = complete communication endpoint.
