# Room: Offensive Security Intro
## Difficulty: Easy
## Date Completed: 

---

## Summary
This room teaches the basics of hacking for complete beginners.  
You learn how hackers think, how to start a lab, how to find hidden pages, and how to attack a simple admin login page.

There are only 4 tasks, and each one is hands‑on and easy to follow.

---

## Task 1 — Think Like a Hacker
- You learn that hackers look for weaknesses.
- You learn to explore a website and look for anything unusual.
- The goal is to understand the attacker mindset.

---

## Task 2 — Starting the Lab
- You start the TryHackMe machine.
- You connect to it in your browser.
- You get access to a simple website you can safely hack.

---

## Task 3 — Find Hidden Pages
- You explore the website.
- You look for hidden pages like `/admin`, `/hidden`, `/backup`, etc.
- This teaches basic **recon** and **directory discovery**.

---

## Task 4 — Attack the Admin Page
- You find the admin login page.
- You try simple username/password combinations.
- You learn how weak passwords can be a security risk.
- After logging in, you complete the room.

---

## What I Learned (Easy)
- How hackers explore websites.
- How to start a hacking lab in TryHackMe.
- How to find hidden pages.
- How weak passwords can be exploited.
- My first hands‑on hacking experience.

---

This was a very beginner‑friendly room.
