# 1. Introduction to Cyber Security

## Summary
This room teaches the basics of cyber security.  
You learn what threats are, what attacks are, and why security matters.

## What I Learned
- Cyber security protects computers and data.
- Threats = things that can cause harm.
- Vulnerabilities = weaknesses.
- Attacks = actions taken by hackers.
- Defence = ways to protect systems.

---

# 2. Defensive Security Intro

## Summary
This room explains how defenders protect systems from attacks.

## What I Learned
- Defensive security = stopping attacks.
- Monitoring helps detect suspicious activity.
- Logs show what happened on a system.
- Tools like firewalls and antivirus help protect networks.

---

# 3. Offensive Security Intro

## Summary
This room teaches the basics of hacking from the attacker’s side.  
You explore a website, find hidden pages, and attack a simple admin login.

## What I Learned
- Hackers look for weaknesses.
- You can find hidden pages by exploring.
- Weak passwords are easy to break.
- Offensive security = testing systems by attacking them (legally).
