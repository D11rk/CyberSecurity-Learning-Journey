## Linux File System Structure

### `/`
Root of the entire system.

### `/home`
User home directories.  
Example: `/home/d11rk`

### `/root`
Home folder for the root (admin) user.

### `/etc`
System configuration files.

### `/bin`
Basic commands like `ls`, `cp`, `mv`.

### `/usr`
User-installed programs and libraries.

### `/var`
Variable data (logs, caches, databases).

### `/tmp`
Temporary files.

### `/opt`
Optional software.

---

## Paths
### Absolute Path
Starts from `/`  
Example:  
`/home/d11rk/Documents`

### Relative Path
Based on current location  
Example:  
`cd Documents`

---

## Basic Navigation Commands
- `pwd` → show current directory  
- `ls` → list files  
- `cd` → change directory  

Examples:
```
cd /
cd /home
cd ..
cd ~/Documents
```
