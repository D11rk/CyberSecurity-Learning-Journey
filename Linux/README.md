
# Linux Learning Path

This folder contains my full Week 2 Linux fundamentals journey.  
Linux is essential for cybersecurity, servers, hacking, scripting, and understanding how real systems work.  
Each day builds on the previous one, starting from the basics and moving toward practical skills.

---

### **Day 1 — Linux Intro + File System**

- What a distro is
- Linux directory structure
- Absolute vs relative paths
- Basic navigation (`ls`, `cd`, `pwd`)

### **Day 2 — Basic Commands**
- Core Linux commands
- File operations
- Viewing files
- Manual pages
- Command history

### **Day 3 — Files & Editing**
- Creating files
- Editing with nano/vim
- Redirecting output
- Pipes

### **Day 4 — grep + find**
- Searching inside files
- Searching for files
- Useful flags
- Combining commands

### **Day 5 — Permissions**
- Users, groups, others
- rwx permissions
- chmod, chown, chgrp
- Permission numbers

### **Day 6 — Users + sudo**
- Creating users
- Switching users
- /etc/passwd and /etc/shadow
- Groups
- Privilege basics

### **Day 7 — Practice + Review**
- Full command practice
- Navigation
- Editing
- Searching
- Permissions
- User management
